Using the notebook

  • A notebook is a list of cells. Code cells run Python; text cells hold notes written in Markdown (# headings, **bold**, - lists).
  • All cells share the same variables, so a cell can use what an earlier cell made. Run cells from top to bottom, or press Run all.
  • The last line of a code cell is shown if it is a value: a number, a list, a pandas table. End it with ; to hide it. display(x) shows something from the middle of a cell.
  • Plots made with matplotlib or seaborn appear under the cell.

Keys

  • Shift + Enter run the cell and go to the next · Ctrl + Enter run and stay · Alt + Enter run and add a cell below
  • Ctrl + Space suggestions, including the methods of your variables (type df.) · ↑ / ↓ at the edge of a cell moves to the next cell

Libraries and data

  • numpy, pandas, scipy, scikit-learn, matplotlib and seaborn are loaded automatically the first time a cell imports them.
  • Other libraries: Packages in the toolbar, or a cell with %pip install name. Most libraries in the Pyodide collection work (statsmodels, sympy, networkx…), as do pure-Python libraries from PyPI.
  • Use Files to add your own data (CSV, Excel, text) and read it with pd.read_csv("data.csv"). Files your code writes can be downloaded from there too.

Limits

  • Python runs inside the page (WebAssembly), on one processor core, with no GPU. Classic machine learning and small neural networks run well; large models are slow.
  • PyTorch and TensorFlow are not available: they do not run in WebAssembly. Neural networks can be built with NumPy or scikit-learn's MLPClassifier / MLPRegressor.
  • input() and internet access from Python are not available.
  • Stop restarts Python, which clears the variables (the browser cannot pause Python in the middle of a cell). The desktop app can stop a cell and keep them.

Saving

  • Your notebook is kept in this browser automatically. Save downloads it as a Jupyter notebook (.ipynb) that Jupyter, VS Code and Google Colab can open; Open loads one.
