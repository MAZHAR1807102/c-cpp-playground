Insertion Sort, step by step

Like sorting a hand of cards: the left part is kept sorted, and each new key slides left past the larger keys until it reaches its place. Green cells are the sorted part; the orange cell is where the key landed.

Pseudocode

  1. for j ← 2 to n
  2. key ← A[j]
  3. i ← j − 1
  5. A[i+1] ← A[i] ▷ shift right
  6. i ← i − 1
  7. end while
  8. A[i+1] ← key
  9. end for

Variables

Each shift removes one inversion, so at the end shifts = inversions.

Trace

Same layout as the table in the lecture note. A row appears each time a key is placed.

Why it is correct

At the start of each pass of the for loop, A[1..j−1] holds the original first j−1 keys in sorted order. The while loop moves every larger key one place right and stops at the first A[i] ≤ key, so placing the key at A[i+1] keeps A[1..j] sorted.

Cost

Already sorted: no shifts, n − 1 comparisons, Θ(n). Reversed: every key goes to the front, n(n−1)/2 shifts, Θ(n²). Random: about n(n−1)/4 shifts, still Θ(n²). In-place, stable with the strict > test, adaptive and online.
