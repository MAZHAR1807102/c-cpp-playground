Bubble Sort, step by step

Scan left to right, compare each pair of neighbours and swap them if they are out of order. After each pass the largest remaining key has bubbled to the end. A pass with no swap means the array is sorted, so we stop early.

Pseudocode

  1. for pass ← 1 to n − 1
  2. swapped ← false
  3. for i ← 1 to n − pass
  5. swap A[i] and A[i+1]
  6. swapped ← true
  7. end if
  8. end for
  9. if not swapped
  10. break ▷ already sorted
  11. end if
  12. end for

Variables

Each swap of neighbours removes exactly one inversion, so at the end swaps = inversions.

Why it is correct

After pass p, the last p positions hold the p largest keys in sorted order: during the pass the largest key of A[1..n−p+1] is carried along by every comparison. If a pass makes no swap, every neighbouring pair is in order, so the whole array is sorted and the early exit is safe.

Cost

Pass p makes n − p comparisons, n(n−1)/2 in total without the early exit. Sorted input with the flag: one pass, Θ(n). Reversed: Θ(n²) comparisons and swaps. Same number of swaps as insertion sort makes shifts, but far more comparisons, so it is the slowest of the three in practice. In-place and stable with the strict > test.
