The N-Queens problem, step by step

Place n queens on an n × n chessboard so that no two attack each other: no shared row, column or diagonal. Backtracking places one queen per row, tests each square, and undoes the last choice as soon as a row has no safe square left, so it never explores a branch that is already hopeless. Min-conflicts instead starts from a full board and repairs it.
