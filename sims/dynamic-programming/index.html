Dynamic programming, step by step

Dynamic programming solves a problem by combining answers to overlapping subproblems, computing each one only once and storing it in a table. It applies when an optimal solution is built from optimal solutions of smaller subproblems (optimal substructure). Watch each table fill in, see which earlier cells every entry is built from, then follow the stored choices back to the solution.
