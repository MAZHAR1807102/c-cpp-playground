        Blind or heuristic?

        All of these are the same loop: take a node off the frontier, test it, add its children. Only the choice of which node to take next changes. BFS takes the oldest, DFS the newest, UCS the cheapest so far (g), greedy the one that looks nearest the goal (h), and A* the best estimate of the whole path (g + h).

        Admissible and consistent

        h is admissible if it never overestimates: h(n) ≤ h*(n), the true cost to the goal. Then A* tree search is optimal. h is consistent if h(n) ≤ c(n, n′) + h(n′) on every edge. Then f never decreases along a path, and A* graph search is optimal too. Every consistent h is admissible.

        Why test the goal on selection?

        UCS and A* stop when the goal is taken off the queue, not when it is first generated. A cheaper path may still be waiting. In the Romania graph, Bucharest is first reached by the 450 route through Fagaras; it is only selected after the cheaper 418 route through Pitesti is found.

        Try this

        Open the Greedy trap. Greedy and BFS return S–A–D–G (cost 11), while UCS and A* find S–B–C–G (cost 7). Hill climbing stops at A because no neighbour has a lower h. Then set C=10 in the heuristic (its true cost to G is 3): h is no longer admissible, and A* also returns the cost-11 path.
