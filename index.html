      How it works and what is supported
      
    
        
  • Everything runs in your browser; nothing is sent to a server. Each language's tools download the first time you use that language and are cached after that.
    • 
        
  • C and C++: Clang/LLVM 22 compiled to WebAssembly (the YoWASP build), about 100 MB. Programs run as WebAssembly (WASI) with browser_wasi_shim in a separate worker.
    • 
        
  • Python: CPython 3.14 compiled to WebAssembly (Pyodide), about 14 MB, with the whole standard library (math, random, collections and so on). For numpy, pandas, scikit-learn and plots, use the Notebook (switch at the top).
    • 
        
  • Java: OpenJDK's javac and the TeaVM compiler running in the browser (LiveCodes java-wasm), about 8 MB. It understands modern Java (records, switch expressions, text blocks) and runs programs on TeaVM's version of the standard library, which covers the common classes (Scanner, String, Math, ArrayList, HashMap, streams…) but not all of them. An out-of-bounds array access stops the program even inside try/catch; output appears when the program finishes; a run, compiling included, is stopped after 10 seconds.
    • 
        
  • Standard input is the text in the Input box, read all at once. A program that waits for more input than you gave sees end-of-file.
    • 
        
  • #include <bits/stdc++.h> works in C++: it includes every standard header (except <csetjmp> and <csignal>, which WebAssembly cannot support). It makes compiling take a second or so longer.
    • 
        
  • C++ is compiled with -fno-exceptions: throw and try are not available. Threads, networking and files outside the program are not available either.
    • 
        
  • Theme: choose System, Light or Dark in the toolbar; the choice is remembered in this browser.
    • 
        
  • A run is stopped after 5 seconds (Java: 10 seconds), so an infinite loop cannot freeze the page. Output is cut off after 200,000 characters.
    • 
        
  • With Suggestions on, a list of keywords, library names and names from your code appears as you type (pick with Enter or Tab, close with Esc, open it any time with Ctrl + Space). Errors get a short explanation and, when there is an obvious fix, a button that applies it. Untick Suggestions to turn both off.
    • 
        
  • Ctrl + Enter runs immediately. Click a line number in an error message to jump to it. Your code is kept in this browser.
